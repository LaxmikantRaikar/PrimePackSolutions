PRIME PACK SOLUTIONS WEBSITE

Files:
- index.html: website structure and gallery behaviour
- styles.css: all page styling
- paper_bags/: paper bag product images
- cake_box/: cake and bakery box images
- gift_box/: gift box images
- custom_packaging/: custom packaging images

To add another cake box image:
1. Copy the image into cake_box/ (example: cake_box_6.jpeg).
2. Open index.html and find productGalleries > cake_box > images.
3. Add the new path: "cake_box/cake_box_6.jpeg".
The gallery will then include it and the arrow buttons will cycle through all listed images.

The gallery supports left/right arrow keys and Escape to close.
